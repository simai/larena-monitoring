# Larena Monitoring Batch 1 Evidence

This evidence package records the interface-first contract skeleton batch for
`larena/monitoring`.

Scope:

- Health check descriptor and health status contracts.
- Metric descriptor and metric sample contracts.
- Retention policy contract.
- Incident record contract.
- Dashboard snapshot and gateway contracts.

Out of scope:

- Probe runner runtime.
- Metric storage runtime.
- Incident workflow runtime.
- Alert delivery runtime.
- External observability export.
- Persistence, routes, migrations, admin UI or production service providers.
